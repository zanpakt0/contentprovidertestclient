# ContentProvider Test Client

## Описание
Тестовое приложение для проверки работы ContentProvider приложения Heis2025. Позволяет просматривать все записи (включая удаленные) и добавлять новые записи.

## Функции
- **Просмотр всех записей**: Показывает все записи из ContentProvider, включая удаленные
- **Добавление записей**: Возможность создавать новые записи через интерфейс
- **Статус записей**: Визуальное отображение статуса (АКТИВНО/УДАЛЕНО)
- **Обновление данных**: Кнопка для обновления списка записей

## Требования
- Установленное приложение Heis2025 с ContentProvider
- Разрешения на чтение и запись данных ContentProvider

## Использование
1. Запустите приложение
2. Нажмите "Обновить" для загрузки данных
3. Нажмите "Добавить запись" для создания новой записи
4. Заполните текст и нажмите "Сохранить"

## Особенности
- **Безопасность**: Требует специальные разрешения для доступа к ContentProvider
- **Полная видимость**: Показывает все записи, включая логически удаленные
- **Простой интерфейс**: Минималистичный дизайн для тестирования
- **Реальное время**: Автоматическое обновление после добавления записей

## Технические детали
- **Target SDK**: 34
- **Min SDK**: 24
- **Язык**: Java
- **UI**: Стандартные Android компоненты
- **Data Source**: ContentProvider Heis2025

## Разрешения
```xml
<uses-permission android:name="com.example.heis2025.permission.READ_TEXT_RECORDS" />
<uses-permission android:name="com.example.heis2025.permission.WRITE_TEXT_RECORDS" />
```
